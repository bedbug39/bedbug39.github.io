# Siam Ibne Sarwar (Sinan) — Academic Profile One-Page V7

## Direction
Inspired by restrained academic/research portfolio layouts:
- One continuous page
- Name on the left, compact navigation on the top-right
- Home profile card on the right
- Thin dividers and information-dense rows
- Light cream default theme + dark mode
- Scrollspy: the current section is highlighted automatically in the top navigation
- Home → Work → Experience → CV → Contact
- Minimal text, direct actions
- Legacy Projects/Contact URLs redirect to their one-page sections

The live GitHub Pages site is not modified by this package.
